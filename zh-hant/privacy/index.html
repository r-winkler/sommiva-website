隱私權

最後更新： 2026年10月9日

本文為翻譯版本；如有出入，以德文版為準。

摘要

Sommiva不需要帳號、電子郵件地址或電話號碼。你可以自願連結一個電子郵件地址，用來找回你的收款活動；系統只會儲存這個地址的指紋。App沒有廣告、追蹤或分析工具。我們只儲存一起清點所需的資料：顯示名稱、金額、備註、分區和一個匿名使用者ID，購買後另外儲存Pro狀態。資料存放在蘇黎世，並會在固定期限屆滿後自動刪除。

資料控管者

René Winkler
電子郵件：contact@sommiva.com

哪些資料

當你建立或加入收款活動時，Sommiva會在雲端儲存：

  • 顯示名稱：你輸入的名稱。用暱稱就可以。
  • 金額和備註：你記錄的內容，包含時間和分區。請不要在備註中寫下其他人的姓名或地址。
  • 收款活動和分區：收款活動的名稱、貨幣、目標、結束日期和可見範圍，各個分區（例如「吧台」或「北組」），以及誰是負責人或成員。
  • 變更日誌：紀錄的更正和刪除，包含時間和操作者。
  • 匿名使用者ID：一組隨機識別碼，用來將你的紀錄對應到你。它不含姓名，也不含聯絡資料。
  • 與範本比較：如果負責人以先前的收款活動為範本建立新的收款活動，新的收款活動會保留先前收款活動每天和每個分區的小計以及總額，但不含姓名、備註、使用者ID或個別紀錄。這些數字會跟著新的收款活動保留到它被刪除為止，即使先前的收款活動較早被刪除也一樣。只有負責人看得到。
  • Pro狀態：如果你購買Sommiva Pro或恢復購買，Sommiva會連同你的匿名使用者ID一起儲存：Pro是否已啟用或因退款而取消、商店（Google Play或App Store）和時間，另外還有一組假名化的購買參照碼（請見「購買」）。
  • 轉移到新裝置：當你將Sommiva轉移到新裝置時，會短暫產生一筆轉移紀錄，內容包括你的匿名使用者ID、驗證碼的雜湊值（不是驗證碼本身）、時間，以及掃描後新裝置的匿名ID。這筆紀錄最晚會在驗證碼失效（10分鐘）後一天內刪除。新裝置原有的匿名識別碼會在過程中刪除，除非它已連結電子郵件。設定不會一起轉移。
  • 用於找回的電子郵件（自願）：如果你在設定 › 「連結電子郵件」中連結電子郵件地址，Sommiva只會連同你的匿名使用者ID儲存這個地址的指紋（以伺服器的密鑰計算出的雜湊值）和時間，不會儲存地址本身。我們需要這個地址，只是為了寄送你要求的6位數驗證碼給你。每個驗證碼都會產生一筆短期紀錄，內容包括指紋、驗證碼的雜湊值（不是驗證碼本身）、你的匿名使用者ID、嘗試次數和時間，另外還有防止濫用的計數器（每小時的請求次數和每天輸入錯誤的驗證碼次數）。找回時，執行找回的裝置原有的匿名識別碼會被刪除，除非它已連結電子郵件。只有在你要求驗證碼時，我們才會寄信給你；不會寄廣告，也不會寄電子報。

只會留在你裝置上的資料：你的設定（例如語言、外觀、數字格式）、建議的顯示名稱，以及你已連結的電子郵件的縮寫形式（例如「l•••@gmail.com」）。

目的與法律依據

我們處理這些資料，只是為了讓你們能一起記錄金額並查看總額。法律依據是提供你想使用的App（GDPR（歐盟一般資料保護規則）第6條第1項第b款；在瑞士為瑞士聯邦資料保護法）。我們不會分析、出售這些資料，也不會將其用於廣告。

資料存放位置

Sommiva使用Google Ireland Limited及Google LLC提供的Google Firebase（Cloud Firestore、匿名登入，以及用於自動刪除、轉移到新裝置、驗證購買和電子郵件驗證碼的Cloud Functions）。收款活動的資料存放在蘇黎世區域（europe-west6），Cloud Functions也在該區域執行。為了匿名登入，Google也可能在瑞士和歐盟以外的地區處理匿名使用者ID和IP位址等技術資料，特別是在美國；Google為此依據歐盟執委會的標準契約條款。Google依照Firebase資料處理條款，以受託處理者身分處理這些資料。

含有驗證碼的郵件由Infomaniak Network SA（瑞士）以受託處理者身分，從noreply@sommiva.com寄出。你的電子郵件地址和驗證碼只會經過該公司，以便寄送郵件；郵件中不含來自其他伺服器的圖片，也沒有追蹤。

相機與QR Code

Sommiva只使用相機掃描用於加入收款活動或轉移到新裝置的QR Code。相機畫面在你的裝置上分析，既不儲存也不傳送。在Android上，App使用Google ML Kit辨識QR Code。ML Kit會將辨識功能的使用情況和效能資訊傳送給Google，例如裝置和App的資訊；Google用這些資訊來運作和改善ML Kit。在iPhone上，辨識是透過裝置上的Apple功能完成。

防止濫用

為了確保只有正版App能存取服務，並防止有人以人為請求讓服務超載，Sommiva會請Google Play（Android）或Apple（iPhone）確認這是在真實裝置上執行、未經修改的正版App（Firebase App Check搭配Play Integrity，或App Attest和DeviceCheck）。為此，Google或Apple會取得裝置和App完整性的相關資訊，例如App識別碼、App版本和裝置的檢查結果；你的紀錄、顯示名稱和使用者ID不包括在內。App只會從中取得一個短期有效的驗證權杖（token），並在每次向Firebase發出請求時一併傳送。法律依據是我們保護服務免受濫用和不必要費用的正當利益（GDPR第6條第1項第f款）。Google依照Google Play和Firebase的條款處理這些資料，Apple則依照其自身的條款。

誰能看到你的資料

只有同一個收款活動的成員。成員能看到什麼，由負責人決定：全部、只有總額，或只有自己的金額。負責人一律可以看到全部。除非法律要求，例如依主管機關或法院的命令，否則我們不會將任何資料提供給第三方。在這種情況下，我們只會提供已儲存且被要求的資料。

保存期限

收款活動會在連續30天沒有新紀錄後自動結束（最早在結束日期後30天），或在負責人將它結束時結束。已結束和自動結束的收款活動，會在24個月後連同所有紀錄一起刪除；App會在收款活動上顯示刪除日期。負責人可以在此之前隨時刪除收款活動。

定期收款活動（每週、每月或手動分輪次）：每週和每月週期的收款活動，在連續兩輪沒有紀錄後自動結束；手動分輪次的收款活動，在連續30天沒有紀錄後自動結束。只要定期收款活動仍然存在，它的各個輪次會在該輪結束24個月後，連同所有紀錄、小計和日誌紀錄一起刪除；收款活動本身則繼續進行。

Pro狀態和購買參照碼會持續保存，讓你的購買保持有效；「刪除我的資料」不會移除它們。如果你仍然希望刪除，請寫信給我們（之後這個使用者ID的Pro將不再獲得確認）。

已連結電子郵件的指紋會一直保留，直到你在設定 › 「電子郵件」中移除它、連結另一個電子郵件，或選擇「刪除我的資料」為止。驗證碼紀錄最晚會在驗證碼失效（10分鐘）後一天內刪除，防止濫用的計數器最晚在一天後刪除。

你的權利

你可以要求查閱你的資料、更正或刪除資料，以及反對資料的處理。在App中，你可以直接在設定 › 「刪除我的資料」中刪除：你在所有收款活動中的名稱會變成「已刪除的成員」，你的備註會被刪除，已連結的電子郵件也會被移除。你的金額會保留，讓收款活動的總額保持正確。

如果負責人將你從收款活動中移除，你的紀錄會繼續顯示你的名稱並加註「已移除」，讓帳目仍然有據可查。

其他事項請寫信至contact@sommiva.com。你也可以向資料保護監管機關提出申訴，在瑞士為EDÖB（瑞士聯邦資料保護暨資訊專員）。

購買

你可以透過Google Play或App Store購買Sommiva Pro。付款由各商店處理；我們不會收到任何付款資料。購買或恢復購買後，App會將商店的購買憑證傳送到Sommiva後端（位於蘇黎世的Cloud Functions）。後端會向Google Play查詢，或根據Apple的簽章，驗證是否已購買Pro，之後若有購買被退款，也會從商店得知；這時Pro會被取消。

系統只會儲存一組假名化的購買參照碼：商店訂單編號的單向雜湊值（不是訂單編號本身，也不是購買憑證本身），連同該購買所解鎖Pro的匿名使用者ID，以及是否已退款。它只用於確認Pro和對應退款，不含姓名、電子郵件地址或付款資料。

本網站

網站sommiva.com和邀請連結頁面sommiva.app不設定Cookie、不使用追蹤，也不從其他伺服器載入任何內容。這些網站由GitHub Pages（GitHub Inc.，美國）提供。網頁被開啟時，GitHub會處理技術上必要的資料，例如IP位址，以便提供網頁並防範攻擊。在瀏覽器中開啟邀請連結時，這些資料也包括網址中的邀請碼；邀請碼只能用來加入一個收款活動，並在7天後失效。法律依據是我們維護網站安全的正當利益（GDPR第6條第1項第f款）。
